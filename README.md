# ASURADA GSX · Cyber Circuit

使用本次製作的 `Asurada_GSX.glb` 製成的瀏覽器 3D 街機賽車遊戲。四條原創封閉賽道、六條 KML 香港賽段、六關錦標賽，以及最多五名真人的連線房間。保留四款電腦對手、碰撞損傷、退賽及 PIT 維修，並附本機 UrbanGround 實景對照。

## 遊玩

Windows 雙擊 **Start_Game.cmd**；啟動器會開啟本機伺服器並打開 `http://127.0.0.1:8799/`。本機需要已安裝 Node.js 22.15+。所有 Three.js 程式、WebSocket 伺服器程式、車輛模型及素材都在資料夾內，**不需要 npm install 或外部 CDN**。請使用支援 WebGL 2 的瀏覽器。新版預設埠改為 8799，與舊版 8798 分開。

## 2026-11-15 駕駛優化（參考 LibreCorsa）

參考 [LibreCorsa](https://librecorsa.org/) 及其[官方專案](https://github.com/KhazP/librecorsa) 的漸進操控、煞車導線及分段／圈速差功能，為現有遊戲自行實作以下改進，沒有複製對方程式或素材。

- **漸進操控**：油門及煞車逐步輸入；鍵盤高速轉向幅度縮小，放開按鍵回中。煞車優先於油門，暫停、失焦及斷線清除舊輸入。主選單「駕駛設定」可改回「直接操控」，設定在瀏覽器保存；A 左、D 右及 R 回正保持原鍵位。
- **煞車導線**：按 **L** 或頂部按鈕切換。48 個箭頭沿賽道中心顯示，綠色可加速、黃色收油、紅色煞車，並有文字／參考速度提示。速度依彎曲程度、提前煞車距離和車輛損傷估算；PIT 內隱藏主賽道導線。支援四條封閉賽道及六條香港點到點賽段，終點後不會折返顯示。
- **分段計時及即時差值**：單人模式按賽道和車款保存有效最佳一圈／賽段，在相同路程比較目前快慢；S1–S3 按賽道距離三等分，以跨線時間插值計算。首次有效完成後建立參考。碰撞、超出賽道、回正、PIT 或逆行會令該圈不寫入新最佳紀錄；原有闖關、總賽事紀錄仍獨立保留。多人模式顯示連線賽事，個人分段紀錄限單人。
- **標準手掣**：左搖桿轉向、RT 油門、LT 煞車、A 推進器、B 手煞、Y 視角、Start 暫停；搖桿有死區。多人伺服器改為接受有限、受範圍約束的類比輸入，繼續只接受操控、不接受客戶端位置或損傷。

保留原有 **120 Hz 街機物理**；導線是中心路徑的遊玩提示，不是實車最優賽線或安全速度，也未加入 LibreCorsa 的輪胎模擬／方向盤力回饋。實體手掣未作硬件測試，類比解析及伺服器傳輸已自動驗證。新增 `test-driver-aids.mjs`，完整 `npm test` 現有九組測試；規格及結果在 `qa/librecorsa-upgrade-contract.json`、`qa/driver-aids-results.json`，瀏覽器驗證另見 `qa/librecorsa-upgrade-browser.json`。

## UrbanGround 實景對照

UrbanGround 公開版本是 Unity 原生城市探索沙盒，沒有可供本遊戲使用的原生賽車控制器；本次賽車仍由 Three.js 運行。香港賽段的「UrbanGround 實景對照」會開啟本機橋接頁，顯示原生程式的實際畫面，並可選擇六條路線的任何 KML 航點，在原生地圖定位、放大／縮小及返回賽車。

這部電腦已安裝並核對官方 Windows v1.0.0 的 SHA-256：`78e5376b4fea3e15e793d0932eedac88a92d6f6a761bbf5b6af620f67bc06c44`。程式位於 `C:/Users/User/.codex/tools/urbanground/windows/UrbanGround-Windows/UrbanGround.exe`。雙擊 **Start_UrbanGround.cmd** 可啟動或重用本機程式，再在遊戲按實景對照。其他電腦需先安裝[官方 Windows 版本](https://github.com/UrbanGround/UrbanGround/releases)；210 MB 原生程式沒有重複放進遊戲 ZIP。

此版本實際綁定 IPv6 loopback `::1`，因此橋接預設使用 `http://localhost:8081`。只檢查伺服器回應並不足夠；頁面同時顯示 `tiles_progress`、`tiles_settled` 與 `idle`，取得實際畫面後才開放操作。所有位置切換依序執行；若原生程式有評估任務啟用，橋接會拒絕切換位置，不會干擾評估。

已實測告士打道與赤柱峽道兩個座標的定位、原生地圖畫面及縮放。原生串流達到 100%，但部分政府圖塊在這個原生版本出現 KTX2 貼圖載入錯誤，可能保留較低精度表面，不能把 100% 進度當作每塊貼圖完整。這不是完成全路段實景巡查或導航評估；證據在 `qa/urbanground-verification.json` 與相關 PNG。

原生場景使用香港地政總署的 3D Visualisation Map；相關知識產權屬香港特別行政區政府及原資料擁有人。賽車和本機多人可獨立離線運行；UrbanGround 實景串流另外需要資料服務連線。沒有加入外部模型 API 或計費代理評估。

## 朋友連線：互聯網及本機

2026-10-25 使用者確認需要「不同地方，經互聯網連線」後，已啟用只提供遊戲的臨時公開入口。`127.0.0.1` 仍只供同一部電腦使用，遠端朋友須使用公開入口建立的完整房間邀請連結。

目前臨時遊戲入口：<https://algorithms-massage-unless-technologies.trycloudflare.com/?multiplayer=1>。這是臨時連線，房主電腦、遊戲服務、分享入口與 Cloudflare Tunnel 均需保持運行；重啟 Tunnel 後可能取得不同網址，舊邀請會失效。房間本身也會在所有人離開、遊戲服務重啟或四小時到期後關閉。

`public-server.mjs` 在 loopback 8800 提供遊戲靜態檔案、去除原生橋接的 `/api/config`，並把 `/race` WebSocket 轉送至既有 8799 遊戲伺服器，因此經分享入口與本機加入的車手共用同一房間。此入口拒絕 UrbanGround API、原生畫面與對照頁，亦不提供主機端程式或環境檔案。原本 8799 的原生對照功能保留供房主本機使用。

重新啟動分享時，先啟動遊戲，再在專案資料夾執行 `node public-server.mjs`，然後執行已安裝且具有效 Cloudflare 簽章的 `C:/Users/User/.codex/tools/cloudflared.exe tunnel --url http://127.0.0.1:8800 --no-autoupdate`。請使用該次輸出的 HTTPS 網址，而非把 `127.0.0.1` 傳給朋友。

1. 主選單按「朋友連線」，輸入名稱，建立房間。
2. 複製房間連結給朋友，朋友開啟後輸入另一個名稱並按「加入房間」。本機連結只可用另一個同機分頁或瀏覽器測試；跨電腦請使用公開入口。雙方須在房間名單看到彼此，單人錦標賽不會自動互相連線。
3. 房主可選四條原創賽道或六條香港賽段；原創賽道可設定 2、3 或 5 圈，香港賽段固定由起點至終點跑一次。每個房間最多五名真人，不補入 AI。
4. 每位車手按「準備比賽」，房主再按開始，全員共用倒數。
   房間車手可自行選八款賽車（包括紅色 FIRE SUPERION G.T.R）；所有人看到同一名車手的車款一致，並容許同款車重複選用。真人車手共用相同動力及碰撞尺寸，屬街機式近似。只有 GSX 提供現有駕駛艙視角，其他七款使用近／遠追車視角。
5. 比賽中的碰撞、損傷、PIT、圈數、名次及完賽時間由伺服器統一計算。連線房間不會解鎖單人關卡或改寫單人紀錄。
6. 暫停只會停止自己的操控，其他人與計時繼續。失去焦點或超過 400 ms 未收到操控資料，伺服器會自動煞車。R 成功回正加罰三秒。
7. 房主可由暫停選單返回房間，結束本場、重新準備及選擇下一條賽道。房主離開會把管理權交給另一名在線車手；開賽後斷線的車手會退賽，不能中途重入。

WebSocket 在 120 Hz 物理步進下統一模擬，每秒傳送約 20 次狀態，客戶端另有操控預測及畫面平滑。已用兩個獨立遊戲頁面經公開 HTTPS/WSS 入口，實測同房、準備、共用倒數及一方操控後另一方看到位置變化，約 110 ms 延遲。這仍是同一部測試電腦透過互聯網入口的驗證，未代替朋友另一個 ISP／手機的實機測試。房間只保存在伺服器記憶體，伺服器重啟、所有人離開或四小時到期後關閉。每場上限 15 分鐘。

## 碰撞與損壞

- 車況由 100% 開始。撞護欄與撞車都按實際撞擊／相對接近速度計算損傷；同速擦身不會當成高速撞擊。
- 受損後立即減速，並持續降低加速、最高速度及轉向能力。
- 損傷達 35% 時開始冒煙；車身會按前、後、左、右受撞區域產生簡化凹陷。
- 損傷達 65%（車況剩 35%）停用推進器。
- 損傷達 100%（車況 0%）立即 DNF 退賽，引擎停機；本場不計完賽紀錄。
- **R 只回正及加罰三秒，不會修復車輛，也不能復活已退賽的車輛。** 未退賽的車可駛入 PIT 維修；重新開始則會換上完好賽車。
- 相同接觸有短暫防重複計傷時間，避免一個擦碰在每個物理步進都當成一次新撞擊；更猛烈的第二次撞擊仍會計算。
- 對手也有損傷及退賽規則，並會嘗試避開前車／停下的車輛。

損傷與變形是街機式近似，沒有完整軟體車身、零件脫落或真實機械斷裂模擬。

## PIT 維修站

1. 起終點後留意**右側 PIT ENTRY / 60** 指示牌；小地圖的青色支線就是維修區。
2. 駛入開放的入口，PIT 內會自動限速 **60 km/h** 並暫停推進器。
3. 靠右駛入 **SUGO PIT / REPAIR** 綠色維修格，車頭朝向出口，煞車停穩。
4. 系統自動開始維修，顯示剩餘時間。最低約三秒，損傷越重需時越長；車況、車身凹陷、動力及推進器會逐步恢復。
5. 顯示「維修完成」後，沿 PIT 車道駛離並經出口重新加入主賽道。

維修期間賽事計時及電腦對手照常繼續；車輛不能開走或用 R 回正。只有指定維修格內停穩且方向正確才會修復，路邊停車不會補血。已經 DNF 的車輛不能進站復活。

## 內容與技術

- 玩家使用 GSX 原模型；四款對手由 `dist/vehicles.js` 的獨立車體方案建立。
- GSX 原始 514 個物件依材質合併成 20 個車身繪圖網格；對手每車約 4,300–5,400 個三角形，按材質合併以降低繪圖負擔。
- 保留藍白紅塗裝、SUGO、金色輪圈、雙推進器與四眼 AI 內裝。
- 路面、路肩、護欄、霓虹燈、起跑門、車房、城市、山景及海面均由固定種子建立。
- 固定 120 Hz 物理步進，含油門、煞車、速度相關轉向、路肩減速、按車體尺寸計算的碰撞、持續損傷、退賽與能量管理。
- 模型玻璃在遊戲中改用便宜的有色材質；駕駛艙視角隱藏風擋玻璃以保持視線。
- 這是街機原型；沒有真實輪胎／懸掛模擬或完整機械動畫。

## 檢查

`npm test` 執行全部六個檢查程式，不會下載依賴。

`node test-hk-routes.mjs`：核對原始 KML 的 SHA-256、全部六條座標、每個航點及投影反算、單程端點、長路線的空間索引對照、相同種子的場景計畫、建築避開道路，以及四款 AI 車各自完成每條香港賽段與停格維修。結果在 `qa/hk-route-results.json`。

`node test-urbanground.mjs`：用獨立協定夾具檢查 health／state／frame、KML 航點定位、評估任務保護、縮放白名單、同來源限制及原生畫面轉送。這個單元檢查不等於原生實景測試；原生程式的實測另記在 `qa/urbanground-verification.json`。

`node test-championship.mjs`：驗證六關解鎖、通關／失敗／退賽、損壞儲存、重玩及紀錄保存；檢查四條封閉路線不自交，讓同一套駕駛物理跑完各賽道三圈，並在每條賽道實際駛入 PIT、停格修復及駛出。結果在 `qa/championship-results.json`。

`node test-multiplayer.mjs`：兩個獨立 WebSocket 客戶端加入、房主權限、準備限制、選路及同步倒數、操控與一致快照、超時自動煞車、共同碰撞損傷、完賽與返回房間、房主轉移、失效邀請及五人上限。碰撞與終點邊界使用伺服器測試夾具，沒有偽稱真人跑完全場。結果在 `qa/multiplayer-results.json`。

`node test-physics.mjs`：十四組物理檢查，包括左右轉向、碰撞損傷、DNF、三圈競賽，以及 PIT 修復計時、限制條件、進站限速、維修中禁止回正，並用相同駕駛物理由主賽道駛入、停格修復、經出口返回主賽道。結果寫入 `qa/physics-results.json`。

`node test-vehicles.mjs`：用內置 Three.js 檢查四款車的外廓、正常數值、零面積三角形、繪圖網格數及不同幾何，再讓四款對手在全部四條賽道上開啟碰撞與損傷跑三圈。結果寫入 `qa/vehicle-results.json`。此檢查使用 Node.js 22.15+ 的模組解析功能，不需安裝 npm 套件。

加上 `?debug=1` 可開啟 GRAPHICS INSPECTOR，檢查固定視角、線框、賽道邊界、實際 CPU 幀率、繪圖次數與三角形數。此遊戲直接渲染，不使用後期處理；正常畫面即 no-post 基線。原始畫質可切換 HIGH／MED／LOW，調整的是實際渲染解析度。

診斷面板的低速／中速／高速撞擊按鈕會把車放到指定的護欄接近路徑，交由相同的實際物理步進產生碰撞，沒有直接填入車損數值；可用來重現損傷及 DNF。

「PIT 維修驗證」會建立一台受損車並放在維修格，透過同一套停車判定及實際維修計時驗證修復流程。

香港路線另有「固定航點檢視」：進入 `?course=hk-aberdeen-tunnel&debug=1`，選 KML 航點後檢視隧道、終點或任何路段，可切換近／遠／車內視角和線框。此模式固定為 `inspection`，不計時、不完成賽事、不解鎖關卡。道路邊界診斷亦會顯示原始航點標記。
